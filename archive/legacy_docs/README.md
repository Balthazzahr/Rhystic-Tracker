# Legacy Docs & Catalog Showcase Archive

## What was this?
This directory contains standalone documentation showcase assets and duplicate badge SVG files:
- `custom_badges_showcase.html`: A standalone HTML catalog showcase built to review and preview the original 21 achievement badges across Bronze, Silver, and Gold tiers in a browser.
- `badges/`: 66 individual SVG achievement files that duplicate the production vector SVGs in `src/assets/badges/`.
- `logo.png`: A 978KB high-resolution legacy raster PNG logo replaced across all application documentation and headers by the crisp vector SVGs (`docs/assets/RhysticTrackerLogo.svg` and `docs/assets/RhysticTrackerICON.svg`).

## When was it used?
Referenced during documentation generation and browser previews for v1.2.0.

## When was it archived?
Archived October 2026 (v1.7.8 cleanup).
